## Ветки

На GitHub видишь много веток. Для чего они?

### `main`
**Основная ветка.** Здесь живут готовые уроки.  
Это то, что я (учитель) слил.

```bash
git switch main
git log --oneline
```

### `lesson/branches`
Демонстрирует, как выглядит **отдельная ветка**.  
Это ветка, которая отделилась от `main`.

```bash
git switch lesson/branches
git log main..lesson/branches  # что в этой ветке, чего нет в main?
```

### `lesson/pr-demo`
Демонстрирует процесс **pull request**.  
Это ветка, которую я хотел бы слить в `main`, но на примере.

```bash
git switch lesson/pr-demo
```

### `lesson/conflicts-part1` и `lesson/conflicts-part2`
**Две ветки, меняющие ОДНО и ТО ЖЕ место в файле.**  
Когда попробуешь слить обе в `main` — получится конфликт!

Это специально для урока про конфликты.

```bash
git switch lesson/conflicts-part1
git diff main  # вот что в этой ветке

git switch lesson/conflicts-part2
git diff main  # а тут в одном месте совсем другое
```

## Где что смотреть в GitHub

Если откроешь репозиторий на GitHub (https://github.com/HighPolyNeko/test-for-vlad):

### Вкладка "Code"
Видишь файлы, как на диске у себя.

### Вкладка "Commits"
**Вся история по хронологии.** Каждый коммит можно кликнуть и посмотреть, что в нём поменялось.

```
708b700 docs: добавил практические упражнения...
dc7b836 docs: улучшил README с примерами...
...
```

### Вкладка "Branches"
Все ветки. Кликаешь на ветку → видишь коммиты в ней.

### Вкладка "Pull requests"
Тут видны PR. На этом репозитории я их не создавал (нет смысла сливать в себя), но ты можешь попробовать создать свой PR с упражнением!

## ⚡ Быстрый старт на 2 минуты

```bash
# 1. Скачай репозиторий
git clone https://github.com/HighPolyNeko/test-for-vlad.git
cd test-for-vlad

# 2. Посмотри дерево веток
git log --oneline --graph --all

# 3. Переключись между ветками
git switch lesson/branches
git log --oneline -3

git switch main
git log --oneline -3

# 4. Посмотри конфликт
git merge lesson/conflicts-part1
git merge lesson/conflicts-part2  # КОНФЛИКТ!
git merge --abort  # отмена

# 5. Читай уроки
cat README.md
cat lessons/01-osnovy.md
```

## Если запутался

- **Где я сейчас?** → `git status` и `git branch`
- **Что поменялось?** → `git log --oneline --graph --all`
- **Что в этой ветке?** → `git diff main..branch --name-only`
- **Помощь!** → `git <команда> --help` или README.md
